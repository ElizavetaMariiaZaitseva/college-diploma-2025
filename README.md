<h1>Веб-приложение для бронирования билетов на мероприятия</h1>
<h3>О проекте</h3><br>
Это веб-приложение, разработанное в рамках дипломного проекта. Оно позволяет пользователям регистрироваться, просматривать список доступных мероприятий, бронировать билеты и управлять своими заказами. Проект демонстрирует навыки разработки полноценного веб-приложения с клиент-серверной архитектурой, работой с базами данных и ручным тестированием.<br>  
<h3>Актуальность и значимость</h3><br>
В современных условиях цифровизации сферы услуг онлайн-бронирование билетов стало неотъемлемой частью повседневной жизни. Подобные системы востребованы в кинотеатрах, театрах, концертных залах, музеях и на спортивных событиях.<br> Разработка такого приложения позволяет:  <br>
· Отработать навыки полного цикла создания веб-продукта — от проектирования базы данных до тестирования готового интерфейса.<br> · Продемонстрировать понимание клиент-серверного взаимодействия, обработки запросов и валидации данных.<br> · Показать умение работать с современным стеком технологий (Python, Flask, PostgreSQL, HTML/CSS).<br> · Применить на практике методологии тестирования — как на уровне API, так и на уровне пользовательского интерфейса.<br>  
Проект может служить основой для реального сервиса бронирования, а также наглядно демонстрирует компетенции в области бэкенд-разработки, работы с базами данных и QA.<br>  
<h3>Технологический стек</h3><br>
Бэкенд Python 3, Flask База данных PostgreSQL Фронтенд HTML5, CSS, API-тестирование Postman. Среда разработки Pycharm CE <br>
<h3>Функциональные возможности</h3><br>
· Регистрация и аутентификация пользователей (хранение паролей в зашифрованном виде). <br>· Просмотр списка мероприятий с фильтрацией по дате и категории. <br>· Бронирование билетов — выбор мероприятия, количества мест, оформление заказа.<br> · Личный кабинет — просмотр истории бронирований, отмена заказа. <br>· Валидация входных данных на стороне сервера и клиента.<br> · Обработка ошибок с понятными сообщениями для пользователя.<br>

<h3>Тестирование</h3><br>
Проект прошел следующие виды тестирования:<br>
· Функциональное тестирование — проверены все сценарии: регистрация, вход, бронирование, отмена.<br> · UI-тестирование — проверена корректность отображения элементов на всех страницах.<br> · API-тестирование — выполнено с помощью Postman .<br> · Тест-дизайн — при составлении чек-листов использовались техники эквивалентного разбиения и граничных значений.<br>
