##Веб-приложение для бронирования билетов на мероприятия  
О проекте
Это веб-приложение, разработанное в рамках дипломного проекта. Оно позволяет пользователям регистрироваться, просматривать список доступных мероприятий, бронировать билеты и управлять своими заказами. Проект демонстрирует навыки разработки полноценного веб-приложения с клиент-серверной архитектурой, работой с базами данных и ручным тестированием.
Актуальность и значимость
В современных условиях цифровизации сферы услуг онлайн-бронирование билетов стало неотъемлемой частью повседневной жизни. Подобные системы востребованы в кинотеатрах, театрах, концертных залах, музеях и на спортивных событиях. Разработка такого приложения позволяет:
· Отработать навыки полного цикла создания веб-продукта — от проектирования базы данных до тестирования готового интерфейса. · Продемонстрировать понимание клиент-серверного взаимодействия, обработки запросов и валидации данных. · Показать умение работать с современным стеком технологий (Python, Flask, PostgreSQL, HTML/CSS). · Применить на практике методологии тестирования — как на уровне API, так и на уровне пользовательского интерфейса.
Проект может служить основой для реального сервиса бронирования, а также наглядно демонстрирует компетенции в области бэкенд-разработки, работы с базами данных и QA.
Технологический стек
Бэкенд Python 3, Flask База данных PostgreSQL Фронтенд HTML5, CSS, API-тестирование Postman. Среда разработки VS Code Система контроля версий Git / GitHub
Функциональные возможности
· Регистрация и аутентификация пользователей (хранение паролей в зашифрованном виде). · Просмотр списка мероприятий с фильтрацией по дате и категории. · Бронирование билетов — выбор мероприятия, количества мест, оформление заказа. · Личный кабинет — просмотр истории бронирований, отмена заказа. · Валидация входных данных на стороне сервера и клиента. · Обработка ошибок с понятными сообщениями для пользователя.

Тестирование
Проект прошел следующие виды тестирования:
· Функциональное тестирование — проверены все сценарии: регистрация, вход, бронирование, отмена. · UI-тестирование — проверена корректность отображения элементов на всех страницах. · API-тестирование — выполнено с помощью Postman . · Тест-дизайн — при составлении чек-листов использовались техники эквивалентного разбиения и граничных значений.
